# Photo Vacuum [iPhone Only - Phase 1]

Local-first iPhone utility. Zero cloud, zero account.

- Buckets: 0-10, 11-20, 21-30, 31-60, 61-90, 90+ days
- Vault: 14 days before permanent delete + confirm
- Reminder: 10/30/90/180 days (default 30)
- Privacy: No fetch, no network, Airplane Mode verifiable
